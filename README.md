# Cooklang Recipes

The recipes here follow the [Cooklang] format for fully text-based editing.
The project, tools, and apps provide a free open-source ecosystem for creating,
editing, sharing, and publishing recipes.

Refer to the [Getting Started] page for more info, and the [Cooklang
Specification] for the `.cook` file format.

## Convection Steam Ovens (CSO)

As a CSO owner, I have been on a mission to find ways to leverage the product
capabilities to amp up my cooking and take existing recipes to the next level.

## AI Cooking Agent

Many of the recipes have been created or adapted using an AI chat agent which is
tailored to CSO product knowledge, cooking techniques, and creating the best
dining experience (for my household).

I have used this agent to adapt existing recipes, explain why certain modes or
techniques are being used, and also to validate the recipes. I have definitely
caught it making bad decisions on cook times or other variables!

The agent has also created new dishes based on ingredients, descriptions, or
vague references. It has also created a menu plan based around certain themes
or highlighted main courses.

All recipes modified by an AI tool are tagged or labeled as such, but I have
also prepared each of these dishes and made further adjustments as needed.
